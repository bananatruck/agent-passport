# Mock-ups

`desktop.jpg` (1440 wide) and `phone.jpg` (390 wide) are captures of the first page layout, taken in headless Chromium.
They were meant to be generated images, but the image model (Antigravity `generate_image`) returned HTTP 429 (quota exhausted) during the overnight build, so the layout was captured instead.
They show the design direction (passport pages, verdict stamps, the machine-readable zone) before integration; the placeholder data in them is not real check output.
